# Что изменилось

- Главная часть приглашения, изображение и базовые стили сохранены.
- «Фамилия» заменена на «Церковь».
- После сохранения заявки открывается необязательное окно участия.
- Supabase заменён на PostgreSQL через серверный pg-драйвер; конфигурация рассчитана на Neon.
- Вход по email/паролю: scrypt-хеш, серверная сессия, HttpOnly Secure cookie.
- Два администратора создаются локальным скриптом, публичной регистрации нет.
- В кабинете: церковь, дети, участие, дата; три счётчика; изменение, удаление с подтверждением, выход.
- Добавлены параметризованные SQL-запросы, проверка Origin, сохранение без дублей и постоянные ограничения частоты.
- Добавлены миграция, создание аккаунтов, локальный сервер, lockfile и 22 автоматические проверки.
